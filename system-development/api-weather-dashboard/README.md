# Weather Dashboard

天気情報ダッシュボードの公開デモです。公開版では外部APIキーを使わず、サンプル天気データで都市検索、現在地ボタン、お気に入り登録、5日間予報のUIを確認できます。

## 機能

- 都市名検索のUI
- 現在地取得ボタン
- サンプル天気データ表示
- 5日間予報
- お気に入り都市の保存

## セキュリティ方針

- APIキーをコードに埋め込まない
- 公開フロントエンドから外部天気APIへキー付き通信をしない
- お気に入り都市のみLocalStorageに保存

## 実運用時の推奨構成

実際の天気APIへ接続する場合は、APIキーをサーバー側で管理し、フロントエンドには必要な天気データだけを返す構成にします。

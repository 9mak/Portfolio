# AI文章作成アシスタント

APIキーを扱わない、公開ポートフォリオ用の文章生成UIデモです。テンプレート、トーン、文字量を選ぶと、ブラウザ内のサンプルロジックで生成例を表示します。

## 機能

- ブログ記事、商品説明、SNS投稿、メール、プレスリリース、広告コピーのテンプレート
- トーンと文字量の切り替え
- 生成結果のコピー
- ページ内だけの一時履歴

## セキュリティ方針

- APIキー入力欄なし
- 外部AI APIへの通信なし
- 入力内容をLocalStorageに保存しない
- 公開GitHub Pagesで安全に見せるためのデモ構成

## 実運用時の推奨構成

実際にAI APIへ接続する場合は、ブラウザから直接APIキーを送らず、サーバー側で認証、レート制限、ログ削除方針を設計して接続します。

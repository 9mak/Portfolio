# AI Text Analyzer

公開ポートフォリオ用のテキスト分析デモです。APIキーを入力せず、ブラウザ内の簡易ロジックで感情、キーワード、可読性、改善提案を表示します。

## 機能

- 文字数・語数カウント
- 感情スコアのサンプル判定
- キーワード抽出
- 可読性スコア
- 改善提案の表示

## セキュリティ方針

- APIキー入力欄なし
- 外部AI APIへの通信なし
- 入力テキストを保存しない
- 公開デモとして安全に触れる構成

## 実運用時の推奨構成

社内文書や顧客文章を扱う場合は、サーバー側でAPI接続し、保存有無、削除期限、アクセス権限を明示します。

# AI Photo Comedian

写真で一言ジェネレーターのUIデモです。公開ページでは画像を外部送信せず、アップロード画像のプレビューとサンプル一言生成だけを行います。

## 機能

- 画像アップロードとプレビュー
- ボケ、ツッコミ、大喜利、フリーのスタイル切り替え
- サンプル一言生成
- ページ内だけの一時ギャラリー

## セキュリティ方針

- APIキー入力欄なし
- 外部AI APIへの通信なし
- アップロード画像をLocalStorageに保存しない
- ページを閉じるとギャラリーは消える

## 実運用時の推奨構成

実際に画像AIへ接続する場合は、画像の保存期間、削除導線、同意文、サーバー側API接続を用意します。
